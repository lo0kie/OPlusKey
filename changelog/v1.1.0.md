## v1.1.0

首个正式版。此前为 beta 阶段（`v1.0.x-beta`），本版是第一个稳定版。

- 侧键单击、双击、长按重映射
- 动作支持 `native` / `passthrough` / `keyevent:` / `flashlight:` / `shell:` / `intent:` / `app:` / `longpress:`，也可直接写 shell 命令
- 独占输入设备自行判定，用 uinput 转发不拦截的事件，不修改系统分区
- 配置持久化在 `/data/adb/OPlusKey/config.conf`，更新模块不丢
- WebUI 配置界面，常驻看护，daemon 崩溃自动拉起

相比 `v1.0.8-beta`：

- 打包前统一换行符，模块脚本强制 LF，避免 Windows 检出后刷入失效
- 动作预设表独立成文件

> 从 beta 升上来的用户：由于版本号计算方式调整，`v1.0.x-beta` 的 versionCode 会高于原先的
> `v1.0.0`，因此正式版从 `v1.1.0` 开始编号，确保能正常收到更新提示。
